## 📖 About

**DailyTools** is a collection of free browser-based utilities that make common digital tasks faster and easier. Format JSON, compress images, merge PDFs, count words, and more, all in one clean place.

No signup is required for basic tools, and wherever practical, processing happens **directly in your browser**.

## 🔒 Privacy First

DailyTools is designed with your privacy in mind.

- ✅ No signup required for basic tools
- ✅ Browser-based processing wherever practical
- ✅ Files and text are not unnecessarily uploaded to a server
- ✅ No account needed to use the core tools

> 🛡️ **Your data stays on your device whenever the tool can process it locally.**

## ⚡ Getting Started

```bash
# Clone the repository
git clone <your-repository-url>
cd dailytools
```

**Run the frontend**

```bash
cd frontend
npm install
npm run dev
```

**Run the backend** (in a second terminal)

```bash
cd backend
npm install
npx nodemon server.js
```
